## 🎯 What interviewers actually ask about this topic

Only a few things, and they're basic — but getting one wrong looks careless:

- What's the difference between `git fetch` and `git pull`?
- What's the difference between `merge` and `rebase`?
- How do you undo a commit that's already pushed?
- What should never go in a Git repo?
- What's the difference between an image and a container?

All five are answered in `5_interview_qa.md`.
