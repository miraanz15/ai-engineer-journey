## 🔧 When stuck

- `git status` first, always — it tells you exactly what state you're in and what command to run next.
- Stuck in `nano` after a merge/commit message? `Ctrl+O` then `Enter` to save, `Ctrl+X` to exit.
- Multi-line commands with quotes can get mangled on paste — prefer one-line commands with `\n` when possible.
