## Every question uses this format

```markdown
### Q: <the question>

**Simple answer (say this):**
Short. Plain English. What I'd actually say out loud.

**Deeper answer (if they push):**
The detail, the numbers, the trade-off.

**What they are really testing:**
Why they asked. Usually: have I built this, or only read about it?

**Likely follow-up:**
The next question — so I'm never caught out.
```
